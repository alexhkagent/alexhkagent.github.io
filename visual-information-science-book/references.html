A note on sources关于来源的说明

This is a web book, not a systematic review. The reference list is deliberately short and biased toward primary sources and widely used standards. Where a claim is contested, the text says so. Where a number comes from a single laboratory study, it is presented as a hypothesis for your own context, not as a law. 这是一本网页书，而不是系统综述。参考文献刻意保持简短，并偏向一手研究与广泛使用的标准。凡有争议的论断，正文会明确说明。凡来自单一实验室研究的数字，都作为你所在情境的假设呈现，而不是定律。

If you find an error, the correction belongs in the next edition. The book is designed to be revised: each chapter is a separate page, each claim has a source, and the whole thing is built from plain HTML, CSS, and JavaScript. 如果你发现错误，修正应进入下一版。这本书被设计成可修订的：每一章都是独立页面，每一个论断都有来源，而整体只由原生 HTML、CSS 与 JavaScript 构成。
